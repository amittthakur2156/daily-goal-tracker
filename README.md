# 🎯 Daily Goal Tracker

A simple and responsive **Daily Goal Tracker** web application built using **HTML, CSS, and JavaScript**. It helps users create, manage, and track their daily goals with progress updates and theme switching.

---

# 🚀 Features

* ➕ Add new daily goals
* ✅ Mark goals as completed
* 🗑️ Delete goals
* 📊 Automatic progress calculation
* 🌗 Light/Dark theme toggle
* 💾 Data persistence using Local Storage
* 📱 Responsive design for desktop and mobile

---

# 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla)

# ⚡ How It Works

1. Enter a goal in the input field.
2. Click **Add Goal** to add it to the list.
3. Click **✔** to mark a goal as completed.
4. Click **🗑** to delete a goal.
5. The application automatically updates the completion percentage.
6. Use **Toggle Theme** to switch between light and dark modes.
